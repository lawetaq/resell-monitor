# First alpha tester checklist

Thank you for testing Resell Monitor 0.1.0 Alpha. This is an early Linux release,
so reports from different distributions and desktop environments are useful.

## Suggested test

1. Download and launch the Linux x86_64 AppImage.
2. Try **Add to applications** and launch it from the desktop application menu.
3. Select or confirm a location.
4. Open or create a saved search. Do not share its private contents in feedback.
5. Inspect Listings and a listing detail view.
6. Change the color theme, light/dark mode, and interface language.
7. Restart and confirm settings and existing local history remain available.
8. Use Settings → About → Check for updates.
9. Close the application and confirm no window or process remains.

Marketplace access can be degraded by source-side restrictions. Do not send
cookies, credentials, databases, saved-search files, or other personal data with
a report.
