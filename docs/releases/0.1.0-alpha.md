# Resell Monitor 0.1.0 Alpha

Resell Monitor 0.1.0 Alpha is the first public preview of the local marketplace
monitor for reviewing potentially underpriced PC components. It is an alpha
release, not a stable or production-support commitment.

## What's included

- Saved marketplace searches and normalized listing results.
- Deterministic deal analysis, market comparisons, lifecycle tracking, and inbox cleanup.
- Listing thumbnails, RU/EN, and the complete theme set.
- Local SQLite history with safe migration backups.
- TXT, JSON, and HTML exports.
- Native desktop window, portable AppImage use, and optional user-level menu installation.

## Supported platform

The packaged release targets Linux x86_64. It has limited real-environment
coverage and may not run on every Linux distribution, graphics stack, or desktop
environment. Source/development mode remains available for Python 3.13.

## Installation

Portable use:

```bash
chmod +x ResellMonitor-0.1.0-x86_64.AppImage
./ResellMonitor-0.1.0-x86_64.AppImage
```

Menu installation for the current user (no sudo):

```bash
./install_linux_user.sh ./ResellMonitor-0.1.0-x86_64.AppImage
```

Remove only the installed application and menu integration with:

```bash
./uninstall_linux_user.sh
```

## Updating

There is no auto-update. Download a newer release bundle and run its installer
against the newer AppImage. The stable `~/.local/bin/resell-monitor` executable
is replaced while user data remains untouched.

Settings → About can check GitHub Releases manually and open a published release
page. The application does not check in the background or download/install an
update automatically.

## Where your data is stored

Typical Linux locations are:

- Application data and database: `~/.local/share/resell-monitor/`
- Configuration: `~/.config/resell-monitor/`
- Cache: `~/.cache/resell-monitor/`
- Logs and diagnostics: `~/.local/state/resell-monitor/log/`

XDG environment variables may change the expanded paths. Replacing or
uninstalling the AppImage does not remove these directories.

## Known limitations

- Linux x86_64 is the first packaged platform and broad distribution compatibility is unverified.
- Marketplace access can be blocked or degraded by source-side and anti-bot behavior.
- FarPost and Youla do not have full feature parity with Avito; Avito currently has stronger image support.
- Browser-Assisted Retail remains experimental and manual.
- Harmless Qt/Vulkan startup probes or Qt WebEngine teardown warnings may appear on some systems.

## Checksums

The release bundle includes
`ResellMonitor-0.1.0-x86_64.AppImage.sha256`. Verify it from the bundle directory:

```bash
sha256sum -c ResellMonitor-0.1.0-x86_64.AppImage.sha256
```
