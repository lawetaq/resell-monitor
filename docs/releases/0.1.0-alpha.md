# Resell Monitor 0.1.0 Alpha

This is the first public alpha release of Resell Monitor, a local-first desktop
application for reviewing potential resale opportunities in PC-component
marketplace listings. It is an early testing release, not a stable or
production-support commitment. Feedback from Linux testers is welcome.

## Highlights

- Saved searches and normalized listings from Avito, FarPost, and Youla adapters.
- Deterministic deal analysis, market comparisons, lifecycle tracking, and inbox cleanup.
- Listing thumbnails, price history, exports, Russian and English interfaces, and the complete theme set.
- Local SQLite persistence with verified backups before schema migrations.
- Native desktop window and portable Linux AppImage.
- Optional **Add to applications** integration for user-level KDE/GNOME menus.
- Settings → About with version information and a manual GitHub release check.

## Download

The packaged release targets **Linux x86_64**. Download both public assets:

- `ResellMonitor-0.1.0-x86_64.AppImage`
- `ResellMonitor-0.1.0-x86_64.AppImage.sha256`

Linux distribution, graphics-stack, and desktop-environment compatibility has
not yet been validated broadly. Source/development mode remains available for
Python 3.13.

## Installation

Download the AppImage. If it is not executable, use your file manager's
**Properties → Permissions → Allow executing as program** control, then open it.

Resell Monitor remains fully usable as a portable application. To add it to the
current user's desktop application menu, choose **Add to applications** in the
non-blocking prompt or use **Settings → About → Installation**. No sudo is
required.

Terminal fallback:

```bash
chmod +x ResellMonitor-0.1.0-x86_64.AppImage
./ResellMonitor-0.1.0-x86_64.AppImage
```

The release bundle may also contain `install_linux_user.sh` and
`uninstall_linux_user.sh` as advanced integration helpers. They are not required
for normal GUI installation. Uninstalling integration preserves application data.

## Updating

There is no automatic update. **Settings → About → Check for updates** contacts
GitHub only when requested and can open the matching release page. It does not
download, install, restart, or replace the application.

For a future release, download and launch the newer AppImage. Portable users can
replace their existing file; integrated users can choose **Reinstall
integration**. Existing user data remains separate.

## Data and privacy

Typical packaged Linux locations are:

- Application data and database: `~/.local/share/resell-monitor/`
- Configuration and saved searches: `~/.config/resell-monitor/`
- Cache: `~/.cache/resell-monitor/`
- Logs and diagnostics: `~/.local/state/resell-monitor/log/`

XDG overrides can change the expanded locations. Replacing the AppImage or
removing desktop integration does not delete these directories by default.
Marketplace access originates from the user's environment; no telemetry or
automatic update request is added by this release.

## Known limitations

- This is Alpha software and the packaged release currently supports Linux x86_64 only.
- Broad Linux distribution and graphics-stack compatibility remains unverified.
- Marketplace access can be blocked or degraded by source-side and anti-bot behavior.
- FarPost and Youla do not have full feature parity with Avito; Avito currently has stronger image support.
- Browser-Assisted Retail remains experimental and requires deliberate user interaction.
- Harmless Qt/Vulkan probing or Qt WebEngine teardown warnings may appear on some systems.

## Verification

Place the AppImage and checksum file in the same directory, then run:

```bash
sha256sum -c ResellMonitor-0.1.0-x86_64.AppImage.sha256
```

The expected result is:

```text
ResellMonitor-0.1.0-x86_64.AppImage: OK
```

Please use the project's GitHub issue tracker for reproducible problems. Include
your Linux distribution and desktop environment, but do not attach cookies,
credentials, databases, saved searches, or other private application data.
