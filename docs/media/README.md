# Product media

Only approved captures of the real application belong here. The public README
should reference a file only after that file is committed.

Recommended future names:

- `hero.png`
- `listings.png`
- `overview.png`
- `settings.png`
- `theme-switching.gif`
- `scan-results.gif`

Capture real data carefully: remove personal search URLs, account information,
location details that should not be published, and other private content.
